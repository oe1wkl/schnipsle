              Import notes

              Two steps, because the export from Notes leaves out dates and folders:

              1. In Notes, open a folder, select its notes (⌘A) and choose File › Export as › Markdown. Save them into a folder of their own inside one folder for the import, e.g. “Schnipsle-Import”. Do this for each folder you want.
              2. Choose that folder here. Schnipsle then reads the dates and folders of your notes from Notes; macOS asks once whether it may. Nothing in Notes is changed.

              In Simplenote, choose File › Export Notes (in the web app: Settings › Tools › Export Notes). It saves a zip file; choose it here as it is, there is no need to unpack it.

              Tags become hashtags at the end of each note, unless the text has them already. Notes in Simplenote’s trash go to the trash here.

              Choose a folder of HTML files (.html, .htm), such as web pages saved from a browser, or a single file. Each file becomes a note, and its subfolders become tags.

              Pictures saved with a page and pictures embedded in it are copied into the vault, as are files the page links to in the folder. Pictures and links on the web stay links.
