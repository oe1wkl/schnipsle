# Piano sounds for playback

The scores in notes play with these samples (ADR-0035), so playback works offline (N-02). abcjs loads one file per note from `/sounds/<instrument>-mp3/<note>.mp3`.

`acoustic_grand_piano-mp3/` holds the 88 notes of the acoustic grand piano of the Fluid (R3) General MIDI SoundFont by Frank Wen, as converted to MP3 by Benjamin Gleitzman's [MIDI.js Soundfonts](https://github.com/gleitz/midi-js-soundfonts) (`FluidR3_GM/acoustic_grand_piano-mp3`, branch `gh-pages`, downloaded 2026-11-09). That project releases the converted files under the [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/) licence; Frank Wen released the sound font itself under the MIT licence. The files are unchanged.
