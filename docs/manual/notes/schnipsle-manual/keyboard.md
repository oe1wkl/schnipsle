# Keyboard and VoiceOver

Everything in Schnipsle can be done without a mouse on the Mac, and with VoiceOver on the Mac and the iPhone.

## Moving around

- **Tab** goes to the next control, **Shift-Tab** to the one before. A ring shows where you are.
- The note list, the tag tree, the smart folders and the list of versions in the history are one stop each. Inside them:
  - **↓** and **↑** go to the next and the previous item;
  - **Home** and **End** go to the first and the last;
  - **Return** or **Space** opens the item.
- In the tag tree and the smart folders, **→** opens a folder or goes to its first subfolder, and **←** closes it or goes to the folder above.
- The buttons of a row, such as ✎ to rename a tag or ≡ to move a smart folder, come next with **Tab**.
- On the ≡ of a smart folder, the arrow keys move the folder: **↑** and **↓** within its level, **→** into the folder above it, **←** out of its folder.
- **Esc** closes a dialog or the Music menu; you are back where you were before it opened. In the search field, **Esc** clears the search.

## In the editor

- **Tab** leaves the editor for the next control, so the keyboard never gets stuck in it. **⌘]** indents a line or list item, **⌘[** outdents it.
- **⌘-click** (Ctrl-click elsewhere) on a link opens it. On the iPhone, a tap does.
- **⌘Z** undoes, **⇧⌘Z** redoes.

## Menu commands on the Mac

| Keys | Command        |
| ---- | -------------- |
| ⌘N   | New Note       |
| ⌘O   | Open Vault…    |
| ⌘,   | Settings…      |
| ⌘W   | Close Window   |
| ⌘Q   | Quit Schnipsle |

Import…, Imports… and Export… are in the File menu.

## VoiceOver

- Every button says what it does, including those that show only a sign: ‹ goes back to the notes, ✎ renames, ≡ moves.
- Toggles say whether they are on: Pin, Source, Trash, Compare.
- What happens without moving the focus, such as "Saved", a conflict or a finished export, is read out from the status line.
- A rendered score is read as one picture, named by its tunes; its ABC source is read in the editor when the cursor is in it. A song sheet is read as text.
