# Example: Packing list

An example note of the [Schnipsle manual](schnipsle-manual.md): a list of tasks in groups. Pin it while you pack, so it stays at the top of the list.

- Papers
  - [ ] passport
  - [ ] tickets
  - [ ] insurance card
- Clothes
  - [ ] rain jacket
  - [ ] walking shoes
  - [ ] a warm pullover
- Things
  - [ ] phone charger
  - [ ] water bottle
  - [ ] a book

Indent a line with ⌘] on the Mac to put it into the group above it, and outdent it with ⌘[.

Try a smart folder: search for `#schnipsle_manual/travel has:task` and tap **Save**. It shows this list, and any other travel note with tasks you write later ([Tags and smart folders](tags-and-smart-folders.md)).
