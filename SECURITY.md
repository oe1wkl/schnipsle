# Security policy

## Supported versions

Until version 1.0, only the latest release and `main` receive fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Report privately through [GitHub security advisories](https://github.com/oe1wkl/schnipsle/security/advisories/new) or by e-mail to willi@kraml.cc. You will get an answer within 7 days.

Of particular interest: anything that lets note content execute scripts in the app (Markdown, HTML, ABC or ChordPro rendering), escapes the vault folder, or loses or corrupts note data.
